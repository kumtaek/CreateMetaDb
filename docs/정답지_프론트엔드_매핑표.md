## 프론트엔드 검증 쿼리

### JSP 파일 검증
```sql
SELECT * FROM components WHERE component_type = 'FRONTEND_API' AND file_path LIKE '%.jsp';
```

### React/JSX 파일 검증
```sql
SELECT * FROM components WHERE component_type = 'FRONTEND_API' AND file_path LIKE '%.jsx';
```

### Vue 파일 검증
```sql
SELECT * FROM components WHERE component_type = 'FRONTEND_API' AND file_path LIKE '%.vue';
```

### API 호출 관계 검증
```sql
SELECT r.*, c1.component_name as frontend_component, c2.component_name as api_endpoint
FROM relationships r
JOIN components c1 ON r.src_id = c1.component_id
JOIN components c2 ON r.dst_id = c2.component_id
WHERE r.rel_type = 'CALL_API';
```
