# Backend Mapping Report - 누락 원인 상세 분석 리포트

## 📋 요약

**문제**: Java 문자열 기반 SQL 매핑에서 `Path`와 `File` 컬럼이 빈 값으로 표시됨
**원인**: `SqlContent.db`에 데이터 저장 시 `file_path`와 `file_name`이 정상적으로 저장되고 있음 (문제 없음)
**실제 문제**: `backend_mapping_report_generator.py`의 데이터 조회 로직 문제

---

## 🔍 상세 원인 분석

### 1. SqlContent.db 데이터 저장 로직 (정상)

### 2. Backend Mapping Report 데이터 조회 로직 (문제 발견!)

#### 파일: `reports/backend_mapping_report_generator.py` (Line 60-79)

```python
def _get_query_data(self, conn: sqlite3.Connection) -> List[Dict[str, Any]]:
    """SqlContent.db에서 쿼리 데이터 조회"""
    cursor = conn.cursor()
    
    query = """
    SELECT 
        file_path,
        file_name,
        component_name,
        sql_content_compressed
    FROM sql_contents 
    WHERE del_yn = 'N'
    ORDER BY file_path, component_name
    """
    
    cursor.execute(query)
    results = cursor.fetchall()
    
    data = []
    for row in results:
        try:
            sql_content = gzip.decompress(row[3]).decode('utf-8')
        except:
            sql_content = row[3].decode('utf-8', errors='replace') if isinstance(row[3], bytes) else str(row[3])
        
        # ❌ 문제: row[0], row[1]이 NULL이면 빈 문자열로 처리됨
        data.append({
            'file_path': row[0] or '',   # ❌ NULL → ''
            'file_name': row[1] or '',   # ❌ NULL → ''
            'component_name': row[2] or '',
            'sql_content': sql_content
        })
    
    return data
```

**문제점**:
- `row[0]` (file_path)와 `row[1]` (file_name)이 NULL인 경우 빈 문자열 `''`로 처리됨
- 하지만 실제로는 SqlContent.db에 정상적으로 저장되어 있을 가능성이 높음

```sql
-- Java String SQL의 file_path, file_name 확인
SELECT 
    file_path,
    file_name,
    component_name,
    CASE 
        WHEN file_path IS NULL THEN 'NULL'
        WHEN file_path = '' THEN 'EMPTY'
        ELSE 'OK'
    END as path_status,

        WHEN file_name IS NULL THEN 'NULL'
        WHEN file_name = '' THEN 'EMPTY'
```

## 🎯 예상 원인 2가지

### 가능성 1: SqlContent.db에 실제로 NULL 저장됨

**원인**:
- `java_loading.py`의 `_process_collected_queries`에서 `file_id`로 조회 시 결과가 없음
- `rows`가 빈 리스트여서 `file_path`와 `file_name`이 빈 문자열로 설정됨

**확인 방법**:
```python
# java_loading.py Line 231-238
rows = self.db_utils.execute_query(
    "SELECT file_path, file_name FROM files WHERE file_id = ? AND del_yn='N'",
    (file_id,),
    conn=self.conn
)
if rows:  # ❌ rows가 비어있으면?
    file_path = rows[0].get('file_path', '') or ''
    file_name = rows[0].get('file_name', '') or ''
# ❌ else 블록이 없어서 file_path, file_name이 빈 문자열 유지
```

**수정 방안**:
```python

else:
```
