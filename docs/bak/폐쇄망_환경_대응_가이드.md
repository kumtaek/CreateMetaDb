# 폐쇄망 환경 대응 가이드

## 개요

SourceAnalyzer는 폐쇄망 환경에서도 실행 가능하도록 설계되었습니다. 
다만, 일부 리포트 생성 기능에서 외부 CDN을 사용하므로, 폐쇄망 환경에서는 로컬 파일로 대체해야 합니다.

## 외부 의존성 목록

### 1. Mermaid.js (다이어그램 렌더링)
- **사용 위치**: ERD Report, Sequence Diagram Report
- **CDN URL**: `https://cdn.jsdelivr.net/npm/mermaid@10.9.1/dist/mermaid.min.js`
- **로컬 경로**: `projects/{project_name}/report/js/mermaid.min.js`

### 2. html2canvas (이미지 내보내기)
- **사용 위치**: Architecture Report
- **CDN URL**: `https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js`
- **로컬 경로**: `projects/{project_name}/report/js/html2canvas.min.js`

## 폐쇄망 환경 설정 방법

### 방법 1: 로컬 파일 준비 (권장)

1. **Mermaid.js 다운로드**
   ```bash
   # 인터넷이 되는 환경에서 실행
   curl -o mermaid.min.js https://cdn.jsdelivr.net/npm/mermaid@10.9.1/dist/mermaid.min.js
   ```

2. **html2canvas 다운로드**
   ```bash
   # 인터넷이 되는 환경에서 실행
   curl -o html2canvas.min.js https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js
   ```

3. **파일 배치**
   - 다운로드한 파일을 프로젝트 리포트 폴더에 복사:
   ```
   projects/{project_name}/report/js/
   ├── mermaid.min.js
   └── html2canvas.min.js
   ```

4. **자동 폴백**
   - 리포트 생성 시 로컬 파일이 있으면 자동으로 사용됩니다.
   - 로컬 파일이 없으면 CDN을 시도합니다 (폐쇄망에서는 실패).

### 방법 2: 리포트 HTML 수동 수정

폐쇄망 환경에서 리포트가 이미 생성된 경우:

1. 생성된 HTML 파일 열기
2. `<script src="https://cdn.jsdelivr.net/...">` 부분을 찾기
3. 로컬 경로로 변경:
   ```html
   <!-- 변경 전 -->
   <script src="https://cdn.jsdelivr.net/npm/mermaid@10.9.1/dist/mermaid.min.js"></script>
   
   <!-- 변경 후 -->
   <script src="js/mermaid.min.js"></script>
   ```

## 폐쇄망 환경 검증

### 1. 의존성 확인
```bash
# 프로젝트 폴더에서 실행
python temp/check_offline_dependencies.py --project-name {project_name}
```

### 2. 리포트 생성 테스트
```bash
# 리포트 생성
python create_report.py --project-name {project_name} --report-type all

# 생성된 리포트 확인
# projects/{project_name}/report/ 폴더의 HTML 파일을 브라우저에서 열기
```

### 3. 브라우저 개발자 도구 확인
- F12 키를 눌러 개발자 도구 열기
- Console 탭에서 에러 확인
- Network 탭에서 외부 요청 확인

## 주의사항

### 1. Python 패키지
- SourceAnalyzer가 사용하는 모든 Python 패키지는 `requirements.txt`에 정의되어 있습니다.
- 폐쇄망 환경에서는 사전에 패키지를 다운로드하여 설치해야 합니다:

```bash
# 인터넷이 되는 환경에서 실행
pip download -r requirements.txt -d ./packages

# 폐쇄망 환경으로 packages 폴더 복사 후 설치
pip install --no-index --find-links=./packages -r requirements.txt
```

### 2. 데이터베이스 스키마 파일
- DB 스키마 CSV 파일은 프로젝트 폴더에 포함되어야 합니다.
- 경로: `projects/{project_name}/db_schema/`

### 3. MyBatis XML 파일 확장자
- 기본값: `.xml`
- 운영 환경에서 `.dbio` 등 다른 확장자 사용 시:
  - `config/parser/xml_parser_config.yaml` 파일 수정
  - `mybatis_file_extensions` 항목에 확장자 추가

## 트러블슈팅

### 문제: 리포트에서 다이어그램이 표시되지 않음
**원인**: Mermaid.js 로드 실패
**해결**:
1. `projects/{project_name}/report/js/mermaid.min.js` 파일 존재 확인
2. 브라우저 개발자 도구에서 에러 메시지 확인
3. HTML 파일의 script 태그 경로 확인

### 문제: ERD가 생성되지 않음
**원인**: 테이블 관계 정보 부족
**해결**:
1. DB 스키마 CSV 파일 확인
2. MyBatis XML 파일에서 JOIN 관계 확인
3. `--include-orphan` 옵션으로 고아 테이블 포함

### 문제: 고아 엔티티가 발생함
**원인**: 테이블 간 관계가 분석되지 않음
**해결**:
1. MyBatis XML 파일 확장자 확인 (`.xml` 또는 `.dbio`)
2. XML 파일에 JOIN 쿼리가 있는지 확인
3. 설정 파일에서 확장자 목록 확인
