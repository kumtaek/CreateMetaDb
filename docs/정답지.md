# 정답지(기준선) 보완본

본 문서는 SampleSrc 분석 결과 검증 기준과 반복 중단 조건을 정의합니다. 자동 개선 루프는 본 기준을 충족할 때 종료됩니다.

검증·중단 기준
- 누락 허용치: 정답지 대비 누락 0건(필수)
- 초과 허용치: 정답지 수치 대비 +10% 미만까지 OK, +10% 이상이면 오탐/중복으로 간주하여 재개선
- 반복 한도: 최대 3회 자동 개선 후에도 미달이면 수동 점검 대상으로 종료
- 주요 지표: API_URL→METHOD, METHOD→SQL, SQL→TABLE 관계수, JOIN 건수, 컬럼 추출 건수, 총 SQL 수

수작업 기준선 작성 가이드(샘플)
- 범위: `projects/SampleSrc/src` 하위 Controller/DAO/Mapper XML/JPA Repository, 주요 JSP(프론트)
- 방법: 파일별로
  - API 엔드포인트 수(HTTP+경로), 컨트롤러 메서드 수
  - Mapper XML의 쿼리 수(namespace.id)
  - 각 쿼리의 테이블 수, JOIN 수, 대표 컬럼 수(SELECT/WHERE/ON에서 확인)
- 동적 테이블 표기: `users_%s` → `users_{env}` 등 템플릿 그대로 기록

판정 로직(자동화 시 참고)
- 지표별로 (실제값 vs 정답지)를 비교하여 누락=0, 초과<10%이면 통과 처리
- 불일치 항목은 로그에 패턴 요약을 남기고 규칙을 보강한 뒤 재실행

주의
- 본 문서는 기준 정의서로, 상세 정답 수치는 별도 표/CSV로 관리 가능
- 정답치 갱신 시 위의 판정 기준은 그대로 유지하세요
