## 1. 리포트 생성 스크립트 (create_report.py)

### 기본 사용법
```bash
# 모든 리포트 생성
python create_report.py --project-name sampleSrc

# 특정 리포트만 생성
python create_report.py --project-name sampleSrc --report-type erd
python create_report.py --project-name sampleSrc --report-type callchain

# 상세 로그
python create_report.py --project-name sampleSrc --verbose
```

### 리포트 타입 목록
- `callchain` - CallChain Report
- `erd` - ERD Report
- `erd-dagre` - ERD Dagre Report (컬럼 표시)
- `erd-dagre-no-attribute` - ERD Dagre Report (컬럼 미표시)
- `architecture` - Architecture Report
- `architecture-layer` - Architecture Layer Report  
- `sequence` - Sequence Diagram Report
- `query-list` - Query List Report
- `backend-mapping` - Backend Mapping Report
- `all` - 모든 리포트 (기본값)
