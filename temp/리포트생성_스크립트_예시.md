# create_report.py 리포트 생성 스크립트 가이드

## 기본 사용법

### 1. 모든 리포트 생성 (기본)
```bash
python create_report.py --project-name sampleSrc
```

### 2. 특정 리포트만 생성
```bash
# CallChain Report만 생성
python create_report.py --project-name sampleSrc --report-type callchain

# ERD Report만 생성
python create_report.py --project-name sampleSrc --report-type erd

# ERD Dagre Report만 생성 (컬럼 표시)
python create_report.py --project-name sampleSrc --report-type erd-dagre

# ERD Dagre Report (컬럼 미표시)
python create_report.py --project-name sampleSrc --report-type erd-dagre-no-attribute

# Architecture Report만 생성
python create_report.py --project-name sampleSrc --report-type architecture

# Architecture Layer Report만 생성
python create_report.py --project-name sampleSrc --report-type architecture-layer

# Sequence Diagram Report만 생성
python create_report.py --project-name sampleSrc --report-type sequence

# Query List Report만 생성
python create_report.py --project-name sampleSrc --report-type query-list

# Backend Mapping Report만 생성
python create_report.py --project-name sampleSrc --report-type backend-mapping
```

## 리포트 타입 목록

| 리포트 타입 | 설명 |
|------------|------|
| `callchain` | CallChain Report - 호출 체인 분석 |
| `erd` | ERD Report - Mermaid 기반 ERD |
| `erd-dagre` | ERD Dagre Report - Cytoscape Dagre 레이아웃 (컬럼 표시) |
| `erd-dagre-no-attribute` | ERD Dagre Report (컬럼 미표시) |
| `architecture` | Architecture Report - 아키텍처 다이어그램 |
| `architecture-layer` | Architecture Layer Report - 레이어별 아키텍처 |
| `sequence` | Sequence Diagram Report - 시퀀스 다이어그램 |
| `query-list` | Query List Report - 쿼리 목록 |
| `backend-mapping` | Backend Mapping Report - 백엔드 매핑 |
| `all` | 모든 리포트 생성 (기본값) |

## 추가 옵션

### 1. 상세 로그 출력
```bash
python create_report.py --project-name sampleSrc --verbose
python create_report.py --project-name sampleSrc -v
```

### 2. 출력 디렉토리 지정
```bash
python create_report.py --project-name sampleSrc --output-dir /custom/path
python create_report.py --project-name sampleSrc -o /custom/path
```

### 3. ~~고아 테이블 포함 (ERD)~~ - **제거 예정**
```bash
# 현재 기능 (제거 예정)
python create_report.py --project-name sampleSrc --include-orphan

# 수정 후: 무조건 고아 테이블 제외됨 (옵션 제거)
python create_report.py --project-name sampleSrc
```

## 실행 순서 (--report-type all)

1. CallChain Report
2. ERD Report
3. ERD Dagre Report
4. Architecture Report
5. Architecture Layer Report
6. Sequence Diagram Report
7. Query List Report
8. Backend Mapping Report

## 출력 위치

기본 출력: `projects/{project_name}/report/`

생성되는 파일:
- `[sampleSrc]_CallChain_Report_{timestamp}.html`
- `[sampleSrc]_ERD_{timestamp}.html`
- `[sampleSrc]_ERD_Dagre_{timestamp}.html`
- `[sampleSrc]_Architecture_{timestamp}.html`
- `[sampleSrc]_Architecture_Layer_{timestamp}.html`
- `[sampleSrc]_Sequence_{timestamp}.html`
- `[sampleSrc]_QueryList_{timestamp}.html`
- `[sampleSrc]_BackendMapping_{timestamp}.html`

## 주의사항

1. **프로젝트명 대소문자 엄격 구분**
   - 잘못된 예: `python create_report.py --project-name SAMPLESRC`
   - 올바른 예: `python create_report.py --project-name sampleSrc`

2. **메타DB 필수**
   - `projects/{project_name}/metadata.db` 파일 존재 필요
   - 먼저 `python main.py --project-name sampleSrc` 실행

3. **고아 테이블 옵션 (제거 예정)**
   - 현재: `--include-orphan` 옵션으로 제어
   - 수정 후: 무조건 고아 테이블 제외 (옵션 완전 제거)
