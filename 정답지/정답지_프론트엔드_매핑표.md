## 참고
- 정적 JSP/HTML(`user/*.jsp`, `product/*.jsp`, `mixed/`, `error/`, `WEB-INF/views/*`)은 명시적 axios/fetch 호출이 없습니다. 메타DB 프론트엔드 매핑 검증 시 API 연결 여부는 React/Vue/TS 컴포넌트 중심으로 확인하세요.
- TypeScript 컴포넌트(`typescript/components/*.tsx`, `*.ts`)는 UI/서비스 레이어 예제로 존재하며 위 ApiService 호출로 백엔드 연동을 시연합니다.
- [ ] typeList.jsp → /user/types (GET)
- [ ] error.jsp → /user/error (GET)
- [ ] user-list.jsp → /user-management/list (GET)
- [ ] product/list.jsp → /product/list (GET)
- [ ] product/searchResult.jsp → /product/search (GET)
- [ ] partialError.jsp → /mixed/error (GET)
- [ ] syntaxError.jsp → /error/syntax (GET)
- [ ] UserManagementPage.jsp → /user/management (GET)
- [ ] MicroserviceDashboard.jsp → /microservice/dashboard (GET)

## 프론트엔드 검증 쿼리

### JSP 파일 검증
```sql
SELECT * FROM components WHERE component_type = 'FRONTEND_API' AND file_path LIKE '%.jsp';
```

### React/JSX 파일 검증
```sql
SELECT * FROM components WHERE component_type = 'FRONTEND_API' AND file_path LIKE '%.jsx';
```

### Vue 파일 검증
```sql
SELECT * FROM components WHERE component_type = 'FRONTEND_API' AND file_path LIKE '%.vue';
```

### API 호출 관계 검증
```sql
SELECT r.*, c1.component_name as frontend_component, c2.component_name as api_endpoint
FROM relationships r
JOIN components c1 ON r.src_id = c1.component_id
JOIN components c2 ON r.dst_id = c2.component_id
WHERE r.rel_type = 'CALL_API';
```
