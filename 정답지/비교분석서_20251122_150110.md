## 개선/재발 방지
- **분류 우선순위 명확화**: SQL 본문 기반으로 타입 판단 → 불가 시 태그 id/메서드명으로 보조 추론. 현재 메타DB도 이 흐름을 따름(본문 우선, 네이밍은 fallback).
- **`*_Qry_n` 단위 관리**: MERGE/서브쿼리 분리 추출은 설계된 동작이므로 정답지도 `*_Qry_n` 단위로 유지.
- **XML 태그 명칭보다 SQL 본문 우선**: `<delete>`라도 본문이 UPDATE이면 `SQL_UPDATE`로 기록(현행 메타DB와 동일).
- **검증 루틴 유지**: 소스 → 메타DB → 정답지 3단계 대조를 정례화해 소스 변경 시 정답지 불일치 재발을 방지.
