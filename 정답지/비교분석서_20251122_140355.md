## 1. 종합 요약

| 영역 | 정답지 건수 | 메타DB 건수 | 실제 파일 확인 | 평가/원인 |
|------|-------------|-------------|----------------|-----------|
| MyBatis XML | 40 | 51 | 실제 XML 51개(id 기준, ResultMap 1개 제외) | **정답지 오류** (31개 누락, 20개 오기) |

판정: MyBatis는 메타DB 정상·정답지 문제, JPA Native는 메타DB 문제, Java 문자열 SQL은 정답지 보완 필요.

## 2. MyBatis XML 비교

- **실제 파일 스캔**: `projects/sampleSrc/src/main/resources/mybatis/mapper/*.xml` → id 총 52개(그중 `UserResultMap` 1개 제외하면 쿼리 51개).
- **메타DB**: `components.component_type like 'SQL_%'` + `file_path like '%mybatis/mapper%'` → 51개 (모두 실제 XML과 일치).
- **정답지**: 40개만 기재.

## 3. JPA Native SQL (@Query)

- **실제 파일 확인**: `projects/sampleSrc/src/main/java/com/example/jpa/repository/JoinConditionRepository.java`, `MergeQueryRepository.java`, `UserRepository.java`, `OrderRepository.java`, `ProductRepository.java` 내 @Query(nativeQuery=true) 20건 존재(INSERT/UPDATE/DELETE/MERGE/SELECT).
- **메타DB**: `components`에 JPA Repository SQL 0건 (files 테이블엔 경로 등록됨).
- **원인**: `java_loading.py`가 @Query(nativeQuery=true) 파싱 미지원으로 보임.

**결론**: 정답지 기재는 실제와 일치, 메타DB 추출 누락. 로더 개선 필요.

---

## 4. Java 문자열 SQL (DAO 직접 실행)

- **정답지**: 11개 메서드(MergeQueryDao 5, JoinQueryDao 6).
- **메타DB**: DAO 경로(`src/main/java/com/example/dao`)에서 12개 메서드 추출, 각 메서드별 다중 SQL 조각 포함(총 47개 레코드). 추가된 1건은 `CoreSqlPatternDao.executeOracleDataWarehouseQuery` (IMPLICIT JOIN + 윈도우 함수).
- **실제 파일 확인**: `projects/sampleSrc/src/main/java/com/example/dao/CoreSqlPatternDao.java` 676행 부근에 Oracle DW 쿼리 문자열 존재.

**결론**: 메타DB 정상. 정답지에 `executeOracleDataWarehouseQuery` 1건 추가 필요. 테스트 코드(TestComplexJavaPatternDao/TestEnhancedSqlDao)는 정답지 범위 밖이므로 메타DB 추가 인식은 문제 아님.

---

## 5. 조치 제안

1) **정답지 수정**  
- MyBatis 섹션을 실제 XML 기준 51개로 재작성.  
- Java 문자열 SQL 섹션에 `CoreSqlPatternDao.executeOracleDataWarehouseQuery` 추가.  
- (선택) 테스트 DAO 메서드는 제외 규칙 명시.

2) **메타DB 개선**  
- `java_loading.py`에 @Query(nativeQuery=true) 파싱 추가 (@Modifying UPDATE/DELETE/MERGE 포함).  
- 추출 시 `component_name` 형식 `package.Class.method` 유지, SQL 유형 분류(SELECT/INSERT/UPDATE/DELETE/MERGE) 필요.

3) **재검증 절차**  
- 로더 개선 후 `python main.py --project-name sampleSrc --clear-metadb` 재실행.  
- 수정된 정답지와 메타DB를 다시 대조하여 잔여 불일치 확인.

- Java 문자열: 정답지 보완 필요, 메타DB 정상.
