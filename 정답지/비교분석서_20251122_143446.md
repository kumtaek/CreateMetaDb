# 백엔드 매핑표 vs 메타DB 비교 분석 (2025-11-22 14:34:46)

## 요약
- `정답지/정답지_백엔드_매핑표.md`를 최신 `sampleSrc` 코드/메타DB 기준으로 전면 수정 완료.
- 현재 기준 차이 없음: 메타DB(`projects/sampleSrc/metadata.db`)와 정답지의 쿼리 ID/종류가 1:1 일치(MyBatis 51, JPA 86, Java 문자열 12).
- 원인: 이전 정답지가 누락·오류를 포함했기 때문이며, 메타DB는 애초에 올바르게 수집하고 있었음.

## 영역별 검증

### 1) MyBatis (`src/main/resources/mybatis/mapper/*.xml`)
- 메타DB 수집: 51건(모두 `<select|insert|update|delete>` id 기준).
- 정답지 수정: 51건 동일하게 반영(기존의 잘못된/없는 ID 제거, 누락 ID 추가).
- 확인 파일: UserMapper.xml, ProductMapper.xml, UserManagementMapper.xml, ImplicitJoinMapper.xml, MergeQueryMapper.xml.
- 결과: 불일치 없음.

### 2) JPA Repository (`src/main/java/com/example/jpa/repository/*.java`)
- 메타DB 수집: 86건(@Query JPQL·native + 파생 쿼리 네이밍 모두 포함).
- 정답지 수정: 86건 동일하게 반영(기존 20건 → 86건으로 확장).
- 확인 파일: OrderRepository.java, ProductRepository.java, CategoryRepository.java, UserRepository.java, JoinConditionRepository.java, MergeQueryRepository.java.
- 결과: 불일치 없음.

### 3) Java 문자열 기반 SQL (`src/main/java/com/example/dao/*.java`)
- 메타DB 수집: 12건(CoreSqlPatternDao 포함).
- 정답지 수정: 누락되었던 `executeOracleDataWarehouseQuery` 추가하여 12건으로 일치.
- 확인 파일: CoreSqlPatternDao.java, MergeQueryDao.java, JoinQueryDao.java.
- 결과: 불일치 없음.

## 결론 및 개선 사항
- 정답지 최신화로 메타DB와 완전 일치함. 검증 기준으로 바로 활용 가능.
- 향후 파이프라인 변경 시(파서 확장 등) 정답지를 동일 기준으로 재생성/검증하도록 주기 관리 권장.
